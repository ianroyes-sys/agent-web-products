# 90-Day Plan

**One operator. Full-time student. Huntsville, Alabama.**
Start 2026-08-17 · End 2026-11-15 · Royz Media Group

---

## 1. The honest capacity model

This plan is built for **15–20 working hours per week**, not 40. Fall semester is in session for essentially the entire window. Any plan that assumes more will be abandoned in week three, and an abandoned plan is worse than a modest one.

**Realistic weekly shape:**

| Block | Hours | Use |
|---|---:|---|
| Two weekday evenings | 5 | Build, data work, writing |
| Saturday morning | 4 | The week's biggest single task |
| Sunday afternoon | 4 | Outreach writing, research, admin |
| Weekday micro-blocks (30–45 min) | 3 | Sending, replying, follow-ups |
| **Total** | **16** | |

**Two rules that protect this:**

1. **Outreach happens Tuesday and Thursday mornings, before class, no exceptions.** Sending is the task most easily displaced by building, and building is the task most easily displaced by nothing. Fixing the time slot is the only reliable defense.
2. **Exam weeks and finals get a reduced target, planned in advance, not discovered in the moment.** Weeks 8 and 13 below are already de-loaded.

**The spine of the whole plan:** *sell the human version now, build the data now.* Arsenal Index's five one-off reports — Incumbent Vulnerability, Teaming Targets, Capability Gap, Award Velocity, Quarterly Recompete PDF — can be produced by hand from the existing dataset today. They are the first 90 days of revenue. The subscription software is what gets built *with* that revenue and that feedback, not before it.

**Sequence, and why:**

| Order | Product | Rationale |
|---|---|---|
| 1st | **Arsenal Index** | The data already exists. Fastest path to a first dollar and the source of the target list everything else uses. |
| 2nd | **Legible** | Services cash flow. Bigger checks, slower to deliver, sells to the same 426 firms. Starts week 5, once Arsenal outreach has produced conversations. |
| 3rd | **Come Up** | Last. It is the only one whose demand is unproven, and it benefits most from the first two generating public proof. Touch it in weeks 11–13 only. |

## 5. Where it goes wrong

| Failure mode | Signal | Fix |
|---|---|---|
| **Building instead of selling** | Week ends with shipped code and zero emails sent | The Tue/Thu slots are inviolable. Sending precedes building, always. |
| **Sending to the wrong people** | Replies, but all "not for us" | Move up the ICP list. Sellers before end firms. |
| **Unfilled brackets** | Low reply rate on a well-written email | Ten personalized beats a hundred generic. Never batch-send a template. |
| **Waiting for the product** | "I'll start selling when the dashboard is done" | The five one-off reports are sellable today. The dashboard sells nothing that a PDF cannot. |
| **Skipping snapshots** | The archive folder has gaps | Non-recoverable. This is the one thing that cannot be caught up later. |
| **Going dark during exams** | Two silent weeks | Weeks 8 and 13 are pre-de-loaded. Six hours beats zero. |
| **Discounting to win the first logo** | $199 becomes $49 | Discount by adding a report, never by cutting the headline price. |
| **Fabricating traction** | "A few Huntsville firms are using it" | Huntsville is small and everyone knows everyone. One invented reference ends the business. |
